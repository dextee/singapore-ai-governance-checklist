# Singapore AI Governance Readiness Checklist

A portable, evidence-oriented checklist for teams preparing an AI system or agent for production in Singapore.

Use the interactive version on VYR:

**[Open the Singapore AI Governance Readiness Checklist](https://vyrwork.com/tools/singapore-ai-governance-readiness-checklist)**

The checklist converts four governance dimensions into 24 practical review prompts covering owners, permissions, tests, event records, escalation, user transparency, and safe retirement. The individual prompts are VYR's practical interpretation; they are not official IMDA wording.

## What this repository contains

- [`CHECKLIST.md`](CHECKLIST.md): the printable Markdown checklist.
- Links to the primary Singapore guidance used to frame the checklist.
- Evidence examples that help teams distinguish a documented control from a policy statement.

## Scope and limitations

This is a planning aid, not a compliance score, certification, audit, legal opinion, or guarantee. An unchecked item is a discussion prompt, not an automatic finding of non-compliance. Legal, regulatory, privacy, security, employment, consumer, intellectual-property, sector, and contractual questions require accountable review for the actual deployment.
